# QRONOS

QRONOS is a QR-based restaurant menu ordering system that allows customers to scan QR codes, browse menus, and place orders digitally.

## Features

- QR-based menu access
- Digital food ordering
- Frontend and backend separation
- Restaurant management system
- Responsive UI
- API integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React (if used)

### Backend
- Node.js / Express (if used)
- Database integration
- REST APIs
